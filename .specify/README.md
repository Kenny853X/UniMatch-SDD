# GitHub Spec Kit en UniMatch

La integración de Spec Kit se inicializa con los documentos existentes como fuente de verdad:

- `docs/requerimientos.md`: alcance y requisitos.
- `docs/especificaciones.md`: comportamiento funcional y verificaciones.
- `docs/plan-tecnico.md`: arquitectura y tareas.
- `.specify/memory/constitution.md`: principios que deben respetarse.

En esta Fase 4 no fue necesario instalar la CLI: se registró la estructura compatible de memoria y las instrucciones de Copilot dentro del repositorio. Si se usa la CLI posteriormente, debe ejecutarse con Python 3.12 y conservar los documentos anteriores.
